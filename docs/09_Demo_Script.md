# LandOLakesDairyDemo Demo Script

## Demo Goal
Show a compact, end-to-end SDLC story for a dairy catalog application in 15 minutes, covering business intent, requirements, user stories, application flow, admin operations, and API visibility.

## Timeboxed Agenda
### 1. Opening and Context (2 minutes)
- Introduce LandOLakesDairyDemo as a lightweight dairy catalog showcase.
- State that the goal is to demonstrate SDLC outputs, not enterprise complexity.
- Highlight the primary scope: catalog browsing, search, details, admin CRUD, and APIs.

### 2. Project Artifacts (3 minutes)
- Open the project charter and summarize purpose, scope, and success criteria.
- Open the PRD and show how the functional requirements stay intentionally small.
- Open user stories and point out the direct trace from business needs to backlog items.

### 3. User Experience Walkthrough (4 minutes)
- Launch the application on the catalog page.
- Show seeded products across butter, cheese, cream, and half & half.
- Filter by category to show focused browsing.
- Use search to find a specific product.
- Open a product details view and explain the product information shown.

### 4. Admin Experience (3 minutes)
- Switch to the admin experience.
- Add a new sample product.
- Edit an existing product to change description or price.
- Delete a product and confirm it is removed from the catalog.

### 5. API Walkthrough (2 minutes)
- Show the product list API endpoint.
- Show a single-product endpoint by ID.
- Briefly explain create, update, and delete endpoints.
- Mention optional query parameters for category or search if implemented.

### 6. Close (1 minute)
- Reinforce that the demo demonstrates end-to-end SDLC alignment.
- Summarize the value: business clarity, traceable scope, visible functionality, and demo-ready simplicity.

## Presenter Notes
- Keep the focus on traceability from idea to working feature.
- Avoid deep technical discussion unless asked.
- If time runs short, compress the artifact review and prioritize live product and admin flows.

## Suggested Demo Data Callouts
- Butter: salted butter, unsalted butter
- Cheese: cheddar slices, shredded mozzarella
- Cream: heavy whipping cream
- Half & Half: classic half & half

## Expected Outcome
The audience leaves with a clear understanding of how a small product idea can be represented through core SDLC artifacts and translated into a simple, demonstrable web application.
